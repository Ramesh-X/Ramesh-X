> **As AI makes producing code cheaper, architectural, security, product, and organizational judgment becomes the real engineering bottleneck.**

I don't treat that as settled. I test it in writing — from production systems, architecture decisions, security hardening, and team design — and I'm actively looking for practitioners who think I'm wrong. If you've got a counterexample, I want to hear it.

  - 🧭 **Lead** — productivity, hiring, accountability, team design
